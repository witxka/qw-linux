# 🖱️ Peripherals Setup

> Configure your gaming mouse and keyboard for maximum responsiveness. All configuration is done using the **Windows browser** (via the vendor's web-based configurator).

---

## 🖱️ Mouse — G-Wolves HSK Pro 8K

- **Set polling rate to 8K Hz** over the USB dongle.

> 💡 **Note:** The mouse defaults to **1K Hz** out of the box — switching to 8K Hz significantly reduces input latency.

---

## ⌨️ Keyboard — NuPhy Air75 HE

- **Set the keyboard profile to the `C2GO` preset.**

---

### ✅ Summary Checklist

- [ ] G-Wolves HSK Pro 8K polling rate set to 8K Hz
- [ ] NuPhy Air75 HE profile set to `C2GO`
